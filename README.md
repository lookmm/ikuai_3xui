# ikuai_3xui

在 **爱快 iKuai 路由器的 Docker Ubuntu 容器**里，用一个 `start.sh` 自举出「可用 SSH + 3x-ui 面板」的完整环境。

适用场景：路由器性能富余、想在内网跑一个带节点管理的 3x-ui 面板，并且要求**容器重建后配置不丢、SSH 不丢**。

## 特性

- **单文件自举**：只有一个 `start.sh`，容器启动命令直接指向它，无需自制镜像。
- **幂等**：`/etc/.init_done` 标记控制，`restart` 跳过装包；`docker rm` 后重建自动重装。
- **配置持久化**：`/etc/x-ui` 软链到 `/home/xui_config`，`x-ui.db` 落在挂载目录，重建容器后节点不丢。
- **首启随机凭据**：配置区留空的项首次启动随机生成，并自动回写脚本本行，此后固定复用。
- **SSH 开箱可用**：安装并守护 sshd，root 密码与配置区同步。
- **混合入站自动补建**：库里缺 mixed 入站时按配置端口补建，方便直接给代理客户端用。
- **watchdog 保活**：面板 / sshd 异常退出自动拉起。
- **纯文本符号日志**：用 emoji 符号标记关键信息，不使用 ANSI 色码（爱快 Docker 日志页会吞掉 ESC，只剩残渣）；终端与 `/home/init.log` 内容逐字一致，可直接 `grep`。

## 前置条件

1. 爱快已开启 Docker 服务，并有可用的 Ubuntu 镜像（如 `ubuntu:22.04`）。
2. 宿主机上一个目录挂载到容器 `/home`（脚本与面板配置都放这里，**必须持久化**）。
3. 容器网络能出网（装包、拉 3x-ui）。

## 部署步骤

1. 把本仓库的 `start.sh` 上传到宿主机挂载目录（也就是容器里的 `/home`）。

   > 上传时注意：**必须是 LF 换行**。用爱快网页面板的文本框编辑会写成 CRLF，导致容器起不来。用 `scp` / SFTP / vim 均可。

2. 编辑 `start.sh` 头部「★ 配置区」，按需填写（可全部留空，首启自动随机）。

3. 创建容器，启动命令设为：

   ```
   /bin/bash /home/start.sh
   ```

4. 首次启动等待依赖安装与 3x-ui 就位，完成后 `/home/init.log` 与终端日志中会打印：

   - 面板访问地址与防扫路径
   - 面板账号 / 密码
   - 订阅端口、混合入站端口与账密
   - SSH 登录方式

   留空自动生成的凭据同时会被写回 `start.sh` 的配置区，下次启动直接复用。

5. 重启容器（`docker restart`）不会重装，秒起；`docker rm` 重建则自动重装并从 `/home/xui_config` 恢复面板数据。

## 配置区说明

| 变量 | 留空 | 填值 |
| --- | --- | --- |
| `ROOT_PASS` | 首启随机生成并回写本行 | 每次启动按此同步，日志不打明文 |
| `XUI_WEB_PATH` | 首启随机 12 位，格式 `/xxxxxxxxxxxx/` | 面板防扫路径 |
| `XUI_USER` | 首启随机 8 位 | 面板账号 |
| `XUI_PASS` | 首启随机 16 位 | 面板密码 |
| `XUI_PORT` | 不改库中现值 | 同步到库（脚本不校验合法性） |
| `XUI_SUB_PORT` | 不改库中现值 | 同步到库 |
| `XUI_MIXED_PORT` | 不改库中现值 | 同步到库；库里缺 mixed 入站时按此补建 |
| `XUI_MIXED_USER` | 库中有则回填，无则随机 8 位 | 混合入站账号 |
| `XUI_MIXED_PASS` | 库中有则回填，无则随机 12 位 | 混合入站密码 |
| `ROUTER_GW` | 自动探测 | 仅用于启动日志打印访问地址 |

其他开关：

- 日志前缀符号由脚本头部 `E_*` 变量定义，可自行替换成任意 emoji（不再提供 `LOG_COLOR` 彩色开关）。

## 端口

| 端口 | 用途 |
| --- | --- |
| `9090` | 3x-ui 面板 Web |
| `2096` | 订阅服务 |
| `7890` | mixed 入站（HTTP/SOCKS 混合） |

按需在爱快上做端口映射 / 放行。

## 常见问题

**容器起不来，日志报 `$'\r': command not found`**
脚本被存成了 CRLF。用 `dos2unix start.sh` 或 `sed -i 's/\r$//' start.sh` 修正。

**面板数据重建后丢了**
`/home` 没做持久化挂载，或 `/etc/x-ui` 软链失败。确认挂载目录存在且可写。

**重启后又在装包**
`/etc/.init_done` 在容器内而非挂载盘，`docker rm` 后必然重装；这是预期行为。

**忘记面板密码**
直接看 `/home/start.sh` 配置区（首启随机值已回写本行），或改配置区后重启容器同步。
